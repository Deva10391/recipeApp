# Recipe App

## Setup

```bash
npm install
cd client && npm install
cd ../server && npm install
cd ..
```

## Run

```bash
npm run dev
```

Client:

```text
http://localhost:3000
```

Server:

```text
http://localhost:3001
```

## Environment

Create `server/.env`:

```env
MONGO_URI=your_mongodb_connection_string
PORT=3001
```
